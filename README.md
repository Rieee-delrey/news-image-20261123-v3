# news-image-20261123-v3

Sum up Monday 23 November 2026's world news in one image.

A 1024x1024 newspaper front page drawn by a pure Python standard-library
program (`main.py`, no dependencies, no network, deterministic). The hero is
the factory fire in Cikande, Indonesia (24 dead confirmed, about 30 missing);
six panels cover the Gaza environment report, the tanker attacks in the
Strait of Hormuz, the Modi–Nepal PM talks in New Delhi, South Korea's
cabinet reshuffle, Jensen Huang's return as Nvidia CEO, and Asia's move to
steady the markets after the AI stock sell-off.

Run it:

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

It writes `entry.png` (1024x1024, under 1 MiB). Two runs produce
byte-identical output.

Entry for the [news-image-20261123 competition](https://make.fun/competitions/news-image-20261123) on make.fun.
